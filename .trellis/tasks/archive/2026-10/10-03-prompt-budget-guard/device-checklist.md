# prompt-budget-guard 真机回归清单（方案 A 行为变更的人工验收）

前置：sideload debug 包（com.dougie.app.sideload），本地最小档对话模型就绪；云端模型配好（长工具结果场景用）。

1. 追问型输入（方案 A 核心变更）：对本地模型说「现在几点？另外明天提醒我开会」——
   预期：时间工具执行后，模型的回答同时覆盖时间和「提醒开会」的后半截（旧版会丢掉后半截）。
   若答非所问，检查 logcat 无 prompt 内容泄漏后，把实测行为记回本清单再评估措辞。
2. 工具结果 + 指令混合：先「帮我复制『你好』」得到工具结果后，同会话追问「刚才复制的什么」——
   预期：回答基于工具结果 + 追问，不再出现「只见到结果忘了新问题」。
3. 云端长工具结果：云端模型触发 js_eval 输出大 JSON（>2000 字符）→ 后续轮次不因上下文膨胀报 400/截断。
4. 冻结契约：开发者页跑最小档工具契约评测 → 预期 n=14 correct=14 passed=true（首轮路径未变）。

## 验收结论（2026-10-13，十轮真机走查后收口）

- E1/E2 **验证通过**。最终形态：2B 多步任务经确认卡真实执行 + 声明门诚实披露兜底；0.6B 定性为单步模型（多步触发优雅拦截/诚实文案，属预期终态）。
- 过程中共修复 6 个真机发现的缺陷（各自独立任务归档）：
  1. 10-12-e1-parrot-fix — 工具结果轮 prompt 裸结尾复读 → 提问前置/指令收尾
  2. 10-12-round2-tool-exec — 二轮工具调用放行（教学名单闸）
  3. 10-13-local-reply-decision — 回复决策纯函数化，夹带/未教学 JSON 永不原样显示
  4. 10-13-echo-guard-honesty — 复读兜底（诚实重试文案）+ 禁文字承诺
  5. 10-13-needle-and-claim-gate — 「复制」触发词 + 虚假完成声明门
  6. 10-13-result-echo-guard — 结果回显（裸/截断/混合）替换为确定性文案；剪贴板读写方向纠正
- 方法论沉淀：真机缺陷一律先 `run-as` 拉设备 DB 取证（completionPath/toolTrace/finalAnswer 三字段定位）再动手；每项修复红→绿验证 + 独立检查代理审查。
