// 01 · 核心理念

四条设计底线

不是设置里的口号，而是运行时强制的约束：策略引擎的校验链不可绕过。

本地优先

云端默认关闭。顶栏随时可见当前是「仅本地」还是「已授权云端」；设置页「隐私」用同一套事实说明出境、截屏、录音和密钥。

权限先行

日历、定位、麦克风、截屏等按任务申请；权限中心按 L0–L4 逐项开关，可随时在系统设置里收回。

工具可见

每次工具调用在对话里显示卡片，默认收起、可展开看结果；标题自带风险等级。未授权的能力会被跳过，不会静默重试。

记忆可控

对话里可开关记忆门控；记住的事实带来源与置信度，在记忆页统一管理、随时删除。

// 02 · 设备工具

能调用的设备能力

一条可取消、可恢复的 Agent 循环（构建上下文 → 调模型 → 执行工具 → 回填），按风险等级调用以下能力。

L0

时间与电量

时区、时间戳、电量与充电状态，免确认直接执行。

L1 / L2

剪贴板

读写剪贴板。读取要求 Dougie 在前台；写入需确认卡。

L1 / L2

日历

查询日程；写入前先经确认卡。

L1

粗略定位

按任务申请定位权限，不做后台上报。

L1

离线语音输入

ASR 约 230MB 按需下载；录音只在本机转成文字，音频不出境。

L0

离线语音合成

TTS 约 116MB，回复可本地朗读，不依赖任何云服务。

L0

本地意图分类

约 12MB 中文编码器，离线完成意图、槽位与路由。

L1

截屏与模板匹配

MediaProjection 截屏 + OpenCV 只读匹配；截屏像素不出境。

L2

打开应用

仅限「可打开的应用」白名单里的别名，经确认后打开。

L3

短信与拨号

起草短信、打开拨号盘——只是草稿，发送仍由你完成。

L3 · 侧载

无障碍手势

tap_by_text 按文字定位控件并点击、tap_swipe 点击与滑动，需系统授权，可随时收回。

L2 / L4 · 侧载

隔离脚本

沙箱 JS；打开脚本特权后还可用 Python 程序模式。

侧载

端侧对话模型

LiteRT 权重三档：328MB / 756MB / 1.5GB，点「使用」才切换引擎。

// 03 · 风险分级

每一次调用都有等级

对话里的工具卡标题是中文操作摘要，附执行验证徽章；权限中心按同一套等级展示。本地小模型不会被教会 js_eval / py_eval / 无障碍手势。

L0
直接执行无需系统权限，不弹确认
时间 · 电量 · 离线朗读 · 意图分类 · 模板匹配
L1
权限放行需要对应权限，通过后执行
读日历 · 定位 · 麦克风 · 截屏 · 读剪贴板（须前台）
L2
确认卡权限通过后仍弹确认卡
写日历 · 写剪贴板 · 打开应用 · 隔离 JS
L3
确认卡 + 系统能力拒绝或超时都不会执行
起草短信 · 打开拨号盘 · 侧载无障碍手势
L4
脚本特权确认卡；仅侧载开放
隔离 Python · JS 程序模式

// L2 及以上拒绝或超时都不会执行；未授权的能力会被跳过，不会静默重试。

// 04 · 数据出境

出去什么，留下什么，由你决定

默认不上传任何对话。设置页「隐私」卡片写的是同一套事实。

$ dougie privacy --explain

default: allowCloud = false          # 顶栏随时可见当前策略

── 永远留在本机
✓ 截屏像素        云端只看到附件说明
✓ 麦克风录音      只在本机转成文字
✓ API 密钥        EncryptedSharedPreferences，不进 Logcat
✓ 对话与记忆      Room + FTS5 本地数据库

── 打开出境并保存后发送
→ 用户输入与组装后的上下文（含检索到的记忆）
→ 工具结果
→ 非截屏图片附件
→ 目的地：你配置的 OpenAI 兼容 Base URL

# 本仓库不运营 Dougie 云。卸载不会删除你选中的外部模型目录。
# 关闭出境，一切照旧留在设备上。▌
// 05 · 双渠道

两个渠道包，按需选择

构建期固化渠道差异，两包可同机安装。

Play 渠道包com.dougie.app 侧载包com.dougie.app.sideload
给谁只要云端对话与设备工具要端侧模型、悬浮球或无障碍手势
分发GitHub Releases，尚未上架商店GitHub Releases，自行安装
无障碍点击无可选，需系统授权
端侧对话模型无设置中下载并激活
隔离脚本无JS；打开脚本特权后还有 Python

// CI 会跑 checkChannelLeak，确保 Play 包不带侧载能力或模型文件。debug 签名旧包须先卸载再装。
